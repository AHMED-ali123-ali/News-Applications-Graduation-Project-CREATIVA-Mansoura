## Overview 📌 

**News Application** is a mobile application developed as a Graduation Project at **CREATIVA Mansoura**. 

Built with **Flutter & Dart**, the application integrates with an external REST API to fetch and display dynamic, real-time news content. The project showcases hands-on expertise in mobile UI development, API integration, asynchronous programming, JSON parsing, and scalable project architecture.

##  Key Features ✨

| Feature | Description |
| :--- | :--- |
| **📰 Latest News** | Fetch and display live headline news and articles. |
| **🔄 Dynamic Content** | Load news data directly from external endpoints in real-time. |
| **🔌 REST API Integration** | Seamless communication with external news services. |
| **📡 Async Operations** | Non-blocking data fetching for smooth user experience. |
| **🧩 Reusable Widgets** | Highly modular, clean, and reusable UI components. |
| **🎨 Modern UI** | Elegant design adhering to Material Design standards. |
| **📱 Responsive Design** | Optimized layouts across various mobile screen sizes. |
| **🗂️ Clean Structure** | Well-organized architecture for easy codebase maintenance. |
