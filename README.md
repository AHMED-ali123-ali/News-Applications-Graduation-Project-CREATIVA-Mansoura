# 📰 News Applications

A modern **News Application** built with **Flutter & Dart** as a graduation project at **CREATIVA Mansoura**.

The application allows users to browse the latest news dynamically through a **REST API**, with a clean, modern, and user-friendly interface.

## 🔌 API Integration

The application uses an external **News API** to retrieve news articles dynamically.

The API provides information such as:

- News titles
- News descriptions
- News images
- Publication information
- Article data

The received JSON data is parsed into Dart models and displayed through Flutter widgets.
